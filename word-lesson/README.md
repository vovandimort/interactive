# Інтерактивний урок: Microsoft Word (9 клас)

Теми: «Створення в текстовому документі багаторівневих списків, спеціальних символів та формул» і «Робота з формулами».
Весь урок — один файл `index.html` (без бібліотек і сервера).

## Публікація на GitHub Pages
1. Створіть репозиторій на GitHub (наприклад, `word-lesson`).
2. Завантажте `index.html` у корінь (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Через 1–2 хвилини урок буде за адресою `https://<ваш-логін>.github.io/word-lesson/`.

## Як учні передають результат (3 варіанти, від найпростішого)
1. **Файл .txt** — кнопка «Завантажити .txt», учень надсилає файл вам (месенджер, Classroom, пошта). Працює без налаштувань.
2. **Копіювання** — кнопка «Копіювати», учень вставляє текст у чат.
3. **Автоматично в Google-таблицю** (налаштовується один раз, ~3 хв):
   1. Створіть Google-таблицю → *Розширення → Apps Script*.
   2. Вставте вміст файлу `google-apps-script.gs` → збережіть.
   3. *Налаштувати розгортання → Нове розгортання → Веб-застосунок*: *Виконувати від імені: Я*, *Хто має доступ: Усі* → Розгорнути, надайте дозволи.
   4. Скопіюйте URL веб-застосунку (закінчується на `/exec`) і вставте в `index.html` у `CONFIG.WEBHOOK_URL`.
   5. Після кожного тесту в таблиці з'явиться новий рядок (учень, бал, оцінка, код, повний звіт). Учень бачить статус надсилання; при збої браузер робить 3 спроби.
   - Після зміни скрипта потрібне *нове розгортання*.
   - Також можна задати `CONFIG.TEACHER_EMAIL` — з'явиться кнопка «Надіслати email».

Контрольний код у звіті — проста перевірка від випадкових правок, а не криптозахист.

## Налаштування
- Питання тесту — масив `QUIZ` у кінці файлу (`a` — індекси правильних відповідей, `multi:true` — кілька відповідей).
- Оцінка: відсоток × 12 (округлення, мінімум 1).
